# Portadas de videojuegos
Las portadas de este directorio se sirven localmente para mantener el catálogo disponible sin depender de servicios externos.

Los productos incluyen títulos modernos y clásicos como The Legend of Zelda: Ocarina of Time, Sonic the Hedgehog 2 y Final Fantasy VII.
